# Telecom Customer Retention Analysis

# Tools Used
Python (Pandas), Power BI
# Project Overview
Analyzed telecom customer data to understand churn patterns and improve customer retention.

# What I Did
- Performed data wrangling and cleaning to handle missing values and prepare datasets.
- Conducted Exploratory Data Analysis (EDA) to identify churn patterns across tenure and contract types.
- Built an interactive Power BI dashboard to visualize churn rates and customer lifecycle segments.
- Extracted actionable insights on customer retention drivers.

# Project Structure
- `data/` - raw dataset
- `src/` - python code for data cleaning and EDA
- `outputs/` - cleaned datset

# Key Insight
Month-to-month contracts and short tenure customers have the highest churn risk.
